## Decision rules applied (all from the catalog + the 2026-11-03 ruling)
- Restraint / pin / trap / disarm / blinding / maiming that ENDS the encounter -> defeated; a pause that the text
  continues (fight resumes, victim recovers, rescue mid-fight) -> fought/wounded only.
- Stopped / thwarted / foiled / prevented a person, plot or crime -> defeated (2026-10-14 ruling); replaces
  other_verb facts with those verbs.
- Forced to retreat / fled / drove off / fought off / repelled -> defeated + the retreating side escaped (A74).
- Lost limb / impaled / shot: wounded fact always; + defeated only when nothing continues (Klaue pattern).
- A destroyed body whose owner survives, "seemingly" destroyed -> defeated, not killed (A53, A11).
- One act -> drop fought next to the new defeated (A145); a fight stated in its own clause keeps fought.
