# Addendum 7 (DRAFT for the pilot, not yet in the rulings file)

Owner, 2026-11-14: "Isn't there a way to use like previous sentences to fix current passages problems ... Purpose
of our 100% plan is that the Brain understands the whole franchise by every single detail." and "If that leader
is never named in this series, name him 'Kushan Leader' or add a tag with no name, and use 'Kushan Leader'
wherever needed." Design agreed with the owner the same day; this text is what the pilot tests.

## 7.1 Context: the page text around the passage may name who
The labeller, and the model, are given the page text before and after the passage. When the passage leaves a
doer, a target or a name open (a passive with no "by", a pronoun, "the two", "his friends", "the three
students", an epithet, "the imposter"), take it from that context if the context STATES it.
- The row's quote stays inside the passage. The row also carries the context sentence that proves the name
  (`evidence`, copied word for word).
- Context resolves WHO. It never adds an act that only the context narrates: rows are written for what this
  passage states.
- Not allowed, as before: memory of the series, another page, a guess. If the context does not state it, the old
  outcome stands (no row and the tag).
- This replaces "from the passage alone" in B.7 and limits A8, A110, A112 and A130 to the case where the
  context does not state the name either.

## 7.2 An unnamed individual is named by his description
A definite description of ONE specific individual ("the Kushan leader", "the Hollow", "the mayor", "Farnese's
father") is an end. Write it as the passage writes it, without the article, in the fullest form the passage or
context gives ("Kushan leader"), and use that one form for him in every row of the page.
- If the context, or the candidate list of the page, gives his real name, use the name (7.1).
- A description names an individual of THIS page. The store keeps description-ends apart across pages unless
  the wiki links them: "the Hollow" on two pages is two Hollows.
- Still never an end: a crowd, a plural, a kind or an indefinite ("the guards", "five trolls", "a soldier",
  "Hollows").

## 7.3 An arrival is judged with what follows
Someone arrives where a named person is. If his first act toward that person is an attack, in the passage or in
the text right after it, there is no `met` (A145) and the `fought` belongs to the passage that states the
attack. Otherwise it is `met`, also for a hostile arrival.

## 7.4 The model must see what the label uses
Training and extraction inputs carry the same context the labeller had. A label that uses context the model is
not shown teaches guessing.
