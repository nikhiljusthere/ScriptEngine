**Sequencing — explicit order, failure branches pre-committed:**

**Phase 0 — Door pre-check (model-free).** Verify roster and narrative doors exist and are callable. *Branch: a door is missing → build the serving plumbing first (reachability, not extraction, no LLM) → verify → proceed. No census runs through a null door.*

**Phase 1 — R4 (standalone build, model-free, before any timeline census).** Place the 154 unplaced events: 116 generic-heading rows on non-placement pages, 38 Modulo-Chapter docs. Bar: unplaced = 0 or each remainder triaged with a recorded reason (a genuinely unplaceable event is a legal triage outcome, not a silent one). Re-run the cross-page gate and standing gates on the updated corpus. *Branch: an event that won't ground against chapter ranges → triage record (reason + source page), never a forced placement.*

**Phase 2 — Door censuses (model-free, post-R4 corpus).** Roster: 100 fixed enumeration questions. Narrative: 100 fixed chronological queries. Bar: ≥99% reached each; every miss triaged — retrieval-controlled → fix + track; reachability defect → repair chunking/indexing, re-census. *Branch: a door still red after repair → bounded repair budget of 2 iterations; still red → the fork goes to a fresh 5-advisor council on the reachability repair (operating rule: every fork to a council — not a freeze, not a waiver). A red door is never waved through under a "comprehension" label.*

**Phase 3 — Measurement batch (model-free, parallel; Qwen card free of sustained batches):**
- **3a — 8-verb sample.** 100 random plot-summary sentences; record which the eight verbs cannot express. *Pre-committed branch: ≤10 inexpressible → mechanism adequate, no verb work. >10 inexpressible → cross-check those sentences against retrieval (3b): retrieval green on them → record as gate-coarseness diagnostic (B5-class), no build, continue; retrieval red on them → genuine meaning gap → R1 triggers (Phase 4).*
- **3b — Per-dimension retrieval-not-extraction.** 10 questions per dimension: all 12, **plus outcomes ("who won") and causality ("why")** — 140 questions. Green (bundle contains the answering paragraph) → no extraction owed, recorded. Red with the paragraph present in source → chunking repair, not a new table. Red with the content unserved from anywhere → name the layer owed → Phase 4, and it ships with a door (no third corpse).
- **3c — Open-ended census (the "everything" check).** 50 zero-shot character questions, generated with no map reference. Classify each: map-covered (name the dimension) or off-map. ≥3 off-map questions in one class → add that dimension to the map and measure it under 3b. *This is the checkable form of the owner's correction: done is declared against the verified map; the map can only grow via 3c, and every addition is measured before the done-declaration.*
- **3d — Placement-gate audit (the false-negative B demanded).** Stratified sample: 40 agreeing multi-page groups + the 107-disagreement set, re-grounded post-R4 against chapter ranges (same model-free method as the original spot-check). *Branch: 0 unflagged unambiguous misplacements in the agreeing sample → gate trustworthy, recorded. Any found → B5 key-refinement runs before the done-declaration — that is what it is for.*

**Phase 4 — Contingent extraction (only what a red measurement named; LLM work in the final Qwen window, sized to fit before the P6 halt).** Priority order:
1. Reachability repairs named by red doors (from Phase 2; model-free).
2. **R1 per-line meaning index** — iff 3a >10 inexpressible AND 3b red on that content. Priced as a unit: cloned extractor + consumer door reading `semantics` (populating the empty table as R1's home) + reach census on that door.
3. **Outcomes layer** — iff 3b red on "who won" and a chunking repair doesn't close it: field extraction from the existing battle-page result fields (fields, not freeform) + door.
4. **Causality layer** — iff 3b red on "why": per-event causal notes + door. Most likely owed; priced accordingly.
5. **R3 relations era** — iff era/relation questions are red in 3b/3c: era backfill on the 821 rows (enrichment, not a new table); eventive predicates as cross-references into `events` (eventive lives there — no new predicate layer).

Retired, not re-queued: **R2** (3C-GREEN; a red ability-enumeration is repaired as a door/chunking defect first per §12(b), and only reopens as a coverage backfill with door + census if the content is unserved from anywhere) and **R5** (parked; 81% untyped recorded as accepted state in the memo). **If R1 never triggers, `semantics` is formally retired** (drop or deprecate, recorded) — no door-less table survives into done. *Branch: an owed Phase-4 build that cannot fit in the remaining Qwen window → terminal state is not-done + diagnostic memo. Owed work is not skippable; the honest checkable state is reported, not manufactured.*
