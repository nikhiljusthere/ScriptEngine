## 2. Fixes (commit `d9082cb2`; `7b7d8ed3` = dispatch knobs)

- `chunks_for_nodes`: `CROSS JOIN` from `chunk_nodes` (same rows; ORDER BY
  unchanged).
- `neighbours(limit=)`: exact hop-1 fast path when the first hop alone fills
  `limit` (every hop-1 node sorts before every hop-2 node; tie order
  `(is_resolved DESC, id)` verified 60/60 against the full walk); otherwise
  the original walk runs and is cut. Only caller (`hybrid.py`) reads ≤40.
- `schema.sql`: `idx_nodes_name_nocase`, `idx_nodes_label_nocase`,
  `idx_categories_name_nocase`. Created in place on
  `series/marvel/facts.db` (1.5 s; index b-trees only, no table data
  touched — what `initialise()` does on the next `index`). Other series get
  them on their next `index`; results are identical with or without.
- `FactStore.memoised`: store-only answers reused until the store file is
  written (signature = db + non-empty WAL mtime/size; uncommitted
  connections always recompute).
- Reranker/embedder `predict`/`encode` serialised per process (shared HF
  fast tokenizer across the API threadpool).
- `span-recall --workers N`: only the HTTP fetch fans out; verdicts, counts
  and the single-writer sidecar append stay serial, in panel order.
- `SCRIPTENGINE_API_BASE` + supervisor `DOORS`/`WORKERS`/`TAG` env knobs
  (defaults = the original single sequential chain).
